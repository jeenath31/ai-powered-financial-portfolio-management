# 💼 AI-Powered Financial Portfolio Management

An intelligent portfolio management application that helps investors analyze their investments, monitor portfolio performance, assess risk, and receive AI-driven insights for better financial decision-making.

## 📌 Overview

Managing investments across multiple assets can be challenging. This project provides an AI-powered platform that enables users to track their portfolio, analyze historical performance, visualize trends, and receive personalized investment recommendations based on market data and portfolio allocation.

The application combines financial analytics, machine learning, and interactive dashboards to simplify portfolio management for investors.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/AI-Powered-Financial-Portfolio-Management.git
```

### Navigate to project

```bash
cd AI-Powered-Financial-Portfolio-Management
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Backend

```bash
uvicorn main:app --reload
```

### Run Frontend

```bash
npm install
npm start
```
